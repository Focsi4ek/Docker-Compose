## 🐳 Docker Compose

**Docker Compose** — инструмент для запуска и управления многоконтейнерными приложениями.

Конфигурация проекта описывается в файле compose.yaml или docker-compose.yml, где можно определить:

| Возможность | Назначение |
|---|---|
| services | Контейнеры проекта |
| image | Используемый Docker-образ |
| ports | Проброс портов |
| volumes | Постоянное хранение данных |
| networks | Сети между контейнерами |
| environment | Переменные окружения |
| restart | Политика автоматического перезапуска |
| healthcheck | Проверка работоспособности |

## ⚙️ Требования

Для работы с проектами необходимы:

**Docker Desktop**

**Docker Compose**

Для проектов, которые клонируются из внешних репозиториев, также используется:

**Git**

Проверить Docker:

    docker --version

Проверить Docker Compose:

    docker compose version

Посмотреть запущенные проекты:

    docker compose ls

Посмотреть работающие контейнеры:

    docker ps

---

## ▶️ Общий принцип запуска

Перейти в каталог нужного проекта:

    cd 01-joomla

Запустить:

    docker compose up -d

Проверить состояние:

    docker compose ps

Посмотреть логи:

    docker compose logs

Остановить:

    docker compose stop

Запустить снова:

    docker compose start

Полностью остановить и удалить контейнеры:

    docker compose down

## 🛠️ Полезные команды Docker

Показать все контейнеры:

    docker ps -a

Показать Docker-образы:

    docker images

Показать Docker volumes:

    docker volume ls

Показать Docker-сети:

    docker network ls

Просмотреть Compose-проекты:

    docker compose ls

Удалить неиспользуемые Docker-ресурсы:

    docker system prune

Команду необходимо использовать осторожно, особенно при работе с volumes.

## ⚠️ Важно

Некоторые проекты используют одинаковые стандартные порты баз данных. Если при запуске появляется ошибка:

    port is already allocated

необходимо проверить работающие контейнеры:

    docker ps

и остановить проект, занимающий нужный порт.
